    Where each model comes from

    Nvidia agreed in September 2026 to buy Hugging Face, the main place open models are published. This map shows where else each model can be downloaded or hosted, next to whether this computer can run it. Select any cell to check the live listing.

      • Hugging Face, Ollama and ModelScope let you download the model and run it on your own hardware. Microsoft Foundry and Amazon Bedrock run it on their servers, so prompts go to their cloud region.
      • Some open models in Foundry come through its Hugging Face collection. Those are marked “via Hugging Face” and don’t count toward independence.
      • “Hugging Face only” models are worth archiving: keep the model files and their licence on your own storage.
      • Availability checked 27 October 2026. Catalogs change often, so confirm a listing before relying on it.

              Memory
              
      
              Each model needs room for its weights at the chosen compression, plus chat memory (the KV cache) for every person at the chosen conversation length, plus some working space. A little graphics memory is kept back for the screen, and 15% of system RAM (at least 4 GB) for the operating system and office apps.
              
    
              
    
              
      
              Speed
              
      
              To write each token, the computer reads the model’s active weights from memory once, so speed is roughly memory bandwidth divided by active size. That’s why mixture-of-experts models with few active parameters are quick, and why spilling into system RAM slows everything down.
              
    
              
    
              
      
              Accuracy
              
      
              Expect memory and speed within about 25%. Answer quality is a rough ranking for comparing options, not a benchmark score. Figures assume Ollama, LM Studio or llama.cpp with GGUF files; vLLM reserves most graphics memory up front but handles many people at once much better.
